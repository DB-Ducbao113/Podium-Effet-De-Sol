# Showroom model

`model-b-eds-optimized-v1.glb` is the only model in this public source directory. It is the owner-selected Showroom asset and is byte-identical to `source-assets/models/model-b/model-b-eds-optimized-v1.glb`.

The asset is attributed to Luis Adrian V. under CC BY 4.0. Its source, modifications, SHA-256, and release boundaries are recorded in `source-assets/models/model-b/README.md` and `docs/asset-licenses.md`.

The owner approved removal of the former EDS-G01 model on 04/11/2026. Older EDS-G02 and C42 comparison assets are absent from the public source directory. The build guard rejects legacy models in the client artifact.
